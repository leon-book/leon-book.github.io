Delta 中性 · 到期收敛

期现套利(Cash & Carry)

买入现货、同时做空等量交割合约,持有到期。期货到期价格必然收敛到现货,稳稳赚走中间的价差(基差)。

难度 低 典型年化 5%–15% 收益来源:正向基差

1一句话原理

交割合约(如季度合约)有到期日。市场看涨时,期货价往往比现货贵一点,这个差价叫基差。

关键事实:到期时,期货结算价 = 现货价。所以只要现在期货比现货贵,我们就:现货买入锁成本 + 交割合约做空锁卖价,持有到期,基差就是到手利润。这套手法叫Cash & Carry,源自传统商品市场。

和资金费率套利的区别:这里收益来自到期收敛的一次性基差,有明确到期日;资金费率套利则是每 8 小时滚动收费、无到期日。

2运作原理图(基差收敛)

期货价从溢价一路收敛到现货价;做空期货的一方,吃下整段基差。

3本金怎么分配

本金 C 同样要覆盖两条腿:现货全额买入 + 合约保证金。设买入 q 个币:

现货成本 = q × S　　合约保证金 = q × F / L　// S=现货价, F=期货价, L=杠杆 本金 C = q×S + q×F/L　→　q = C / (S + F/L) 到期毛利 = q × (F − S)　// 赚到整段基差
现货腿
必须全额买入(现货没有杠杆),这是资金占用大头。
合约腿
只需保证金 = 名义/杠杆。杠杆越高,占用越少、同本金买更多 q、年化越高——但反向波动时要补仓。
资金占用
要一直持有到到期,期间资金锁死。年化 = 基差% ÷ 剩余天数 × 365,越接近到期、基差越大,年化越高。

5示例走一遍

本金 10,000 U,BTC 现货 60,000、季度期货 61,200(基差 2%),杠杆 2×,距到期 90 天,手续费 0.1%:

步骤数值说明
基差率2.0%= (61200−60000)/60000
买入数量 q0.1105 BTC= 10000 / (60000 + 61200/2)
现货成本6,630 U= q × 60000
合约保证金3,370 U= q × 61200 / 2
到期毛利132.6 U= q × (61200−60000)
手续费−13.5 U≈ 名义 × 0.1%
净利润≈ 119 U90 天锁定
净年化≈ 4.8%= 119 / 10000 / 90 × 365
结论:基差是“已知的到期收益”,确定性高。牛市季度基差常年化 10%+;熊市可能倒挂(期货比现货便宜),此时方向要反过来(买期货、空现货,即反向套利)。

6尾部风险:ADL(自动减仓)

交割合约不只会爆仓,还有一个更隐蔽的机制会让你的对冲在最糟时刻失效。

ADL(自动减仓)是强平流程的最后一道兜底:当某仓位穿仓、保险基金也填不平时,交易所会强制平掉“对手方中盈利且高杠杆”的仓位,按盈利×杠杆排序。交割合约一样有这套机制——它不是永续专属。

对本策略的威胁:币价大跌时,你的空头交割合约正在盈利,恰好是 ADL 的首选目标。空单一旦被强制平掉,对冲腿凭空消失,你只剩现货多单,在下跌行情里被动裸奔——明明是中性对冲、明明在赚钱,却被别人的穿仓连累。这让"Delta 中性"在最糟时刻失效。
更须警惕
交割合约若用币本位结算,因共享更小的保险基金,比 U 本位更容易触发 ADL;临近到期流动性枯竭、结算价跳空也会加剧。
怎么降低
①用低杠杆(ADL 排名靠后);②盯交易所的 ADL 指示灯;③临近到期提前换月/平仓;④留足保证金、分散交易所,被减仓后能快速补建对冲。
