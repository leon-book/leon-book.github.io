统计套利 / 配对交易

找两个走势高度相关的币(如 ETH 与 SOL)。当它们的价差异常拉大时,做多落后的、做空领先的,赌价差回归历史均值。

难度 高 非无风险(赌回归) 收益来源:价差均值回归

1一句话原理

两个相关的币,平时价差(比值)在一个区间里上下波动。统计套利(又叫配对交易)就是:当价差异常拉大时押它回来。

做法:做多相对便宜(落后)的币 + 做空相对贵(领先)的币。两腿等额、方向相反,大盘涨跌互相抵消,只赚价差从“偏离”回到“均值”的那一段——这叫均值回归。

与前面套利的本质差别:资金费率、期现套利有“机制”保证收敛;统计套利只有“历史统计规律”,相关性可能突然失效(价差不回归反而继续扩大)。所以它是“统计套利”不是无风险套利,难度最高,通常同时跑几十上百个配对来分散风险。

2运作原理图(价差回归)

价差碰到 ±2 倍标准差(σ)时开仓,回到均值附近平仓获利。

3本金怎么算

本金 C 分给两腿等额合约(一多一空)。设每腿名义 N、杠杆 L:

两腿名义相等 = N　　每腿保证金 = N / L 本金 C = 2N/L　→　N = C × L / 2 毛利 ≈ (进场偏离% − 平仓偏离%) × N　// 价差收窄的百分点 × 名义
偏离度
用Z 分数衡量价差偏离几个标准差。一般 ±2σ 开仓、回到 0 附近平仓。
分散是命脉
单个配对可能不回归。机构同时跑 50–200 个配对摊平方差,单腿失效不致命。
成本敏感
持有期通常几天到几周,手续费与资金费会侵蚀收益,回归幅度必须盖过成本。

5示例走一遍

本金 10,000 U,进场时价差偏离均值 5%,回归到 1% 平仓,杠杆 2×,手续费 0.1%,持有 15 天:

步骤数值说明
每腿名义 N10,000 U= 10000 × 2 / 2
回归幅度4 个百分点= 5% − 1%
毛利400 U= 4% × 10000
手续费−20 U两腿名义 × 0.1%
净盈亏≈ 380 U价差如期回归
单次收益率3.8%= 380 / 10000
预期年化≈ 92%= 3.8% / 15 × 365(假设持续)
注意:92% 是“假设每次都回归、持续复制”的理论值,极度乐观。真实中会有失败配对(价差不回归反而扩大 → 亏损)。把平仓偏离改成大于进场偏离,计算器立刻显示亏损。所以要靠大量配对分散和严格止损。
