日历价差(跨期套利)

同时操作同一标的的两张不同到期日合约(近月 vs 远月),做多一张、做空另一张,只赌两者“价差”变化,不押单边涨跌。

难度 中 收益随价差波动 收益来源:近/远月价差错位

1一句话原理

同一个币,不同到期日的交割合约价格不一样。通常远月比近月贵(市场看涨),这叫正向市场(Contango)。

做法:做多便宜的一腿 + 做空贵的一腿,赌两者价差(Calendar Spread)回归。因为两腿方向相反,币价整体涨跌会互相抵消——你赚的不是币价,而是价差从“大”变“小”(或反向)的那一段。

与期现套利的差别:期现套利到期必然收敛(确定性高);日历价差是赌价差会收窄,但它也可能继续扩大 → 因此难度与风险更高,属“统计套利”而非无风险套利。

3本金怎么分配

两条腿都是合约,各需保证金。设每腿买卖 q 个币,两腿名义相近:

进场价差 = F远 − F近　// F近=近月价, F远=远月价 保证金合计 = q×F近/L + q×F远/L = C　→　q = C×L / (F近 + F远) 毛利 = (进场价差 − 平仓价差) × q　// 价差收窄则为正
资金效率
两腿都能用杠杆,故同本金可操作的 q 比期现套利大,潜在年化更高。
但风险对称
价差不一定收窄。若不巧继续扩大,两腿价差亏损 × q,可能超过预期收益。
保证金缓冲
建议不要用满杠杆:留出缓冲,避免价差短期剧烈波动时单腿被强平。

5示例走一遍

步骤数值说明
进场价差1,500 U= 61500 − 60000
每腿数量 q0.2469 BTC= 10000 × 3 / (60000+61500)
价差变动1,200 U= 1500 − 300(收窄)
毛利296.3 U= 1200 × 0.2469
手续费−30 U≈ 名义 × 0.1%
净盈亏≈ 266 U价差如预期收窄
年化≈ 32%价差若反向扩大则为亏损
注意:高年化来自“赌对方向”,不是无风险。价差可能扩大而非收窄,把预期平仓价差改成大于进场价差,计算器会显示为亏损——这正是它比期现套利风险高的地方。
