期权套利

期权之间有数学恒等式(平价公式)。只要报价违反它,就能用多条腿组合锁定无风险利润——与币价涨跌完全无关。另有一类"波动率套利"则是带风险的相对价值。

难度 高 无风险类:数学锁定 收益来源:期权定价偏差

1一句话原理

期权分看涨(Call)和看跌(Put)。同到期、同行权价的 C 和 P,它们的价格不是随便定的,受一条铁律约束——看跌-看涨平价(Put-Call Parity)。

C − P = (F − K) × 折现　// 欧式、线性结算;F=同到期期货价, K=行权价 由期权合成的远期价 = C − P + K,理论上必须等于市场期货价 F

如果 C − P + K ≠ F,就出现无风险套利:把贵的一侧卖掉、便宜的一侧买入,差价锁死,到期自动收敛。因为组合对币价完全中性,涨跌都不影响已锁定的利润。

注意分两类:下面的平价/盒式/蝶式是真·无风险(数学保证);波动率套利(第 7 节)严格说是带风险的相对价值,别混为一谈。

3三类无风险套利 + 一类带风险

类型怎么组合锁定收益来源无风险?
平价套利
(转换/反转)		 买/卖 Call + 反向 Put + 期货对冲,合成一个"假远期"去对冲真期货 合成远期与期货价的偏差 ✅ 是(到期收敛)
盒式套利
(Box Spread)		 牛市看涨价差 + 熊市看跌价差(四条腿) 到期收益恒定 = K2−K1;若当前成本 < 折现值即套 ✅ 是(收益恒定)
蝶式套利 买 K1、卖 2 份 K2、买 K3(等间距) 凸性要求组合价 ≥ 0,若报价为负即白赚 ✅ 是(无套利边界)
波动率套利 买/卖期权 + 持续 Delta 对冲 隐含波动率(IV)与实际波动率(RV)的差 ❌ 否(带 Gamma/Vega 风险)
划重点:前三种是数学锁死的真套利;第四种"波动率套利"虽常被叫"套利",但要持续对冲、有模型与对冲成本风险,属于我们文档里统计/相对价值套利那一档,不该算进"稳健理财"。

4本金与成本

期权套利的本金结构比前面复杂,涉及三块:

权利金
买入的期权要付权利金;卖出的期权收权利金但要交保证金。
期货腿保证金
对冲用的期货腿按杠杆占保证金。统一账户里期权与期货可共享抵押。
多腿手续费
最大隐形成本。平价套利 3 条腿、盒式 4 条腿,每条都收费,偏差必须盖过总手续费才净赚。
币本位坑:Deribit 等的 BTC/ETH 期权常以币本位结算,平价/盒式公式要按币本位调整,不能直接套用美元版。本页计算器用简化的线性(USDT 本位)近似,便于理解结构。

6示例走一遍

BTC 30 天期权:C=2,500,P=1,300,K=60,000,同到期期货 F=61,000,手续费 0.1%,1 张:

步骤数值说明
合成远期61,200= C − P + K = 2500 − 1300 + 60000
期货价61,000市场真实报价
定价偏差+200合成比期货贵 → 做 Reversal
操作卖C+买P+买期货卖掉偏贵的合成远期,买入便宜的期货对冲
每份毛利200 U偏差到期收敛锁定
手续费−61 U= 61000 × 0.1%(三腿合计近似)
净利润≈ 139 U与币价涨跌无关
结论:只要偏差 > 手续费就有无风险利润。把偏差调小(如 F 改成 61,150),净利转负,说明手续费是生死线。现实中这种偏差被做市商机器人秒杀,主要出现在波动骤起、冷门行权价、临近到期。

7加密期权的现实

场地集中
BTC/ETH 期权绝大多数在 Deribit,多为欧式,平价公式干净好算。
效率在提升
学术研究发现:到期 ≥ 15 天的 BTC/ETH 衍生品市场已相当有效,无风险套利利润随自动化而显著下降。
窗口极短
做市商机器人把恒等式盯得很死,纯无风险机会几秒内被吃掉;散户手动几乎吃不到。
现实边缘
散户能争取的通常是波动率套利,但那是带风险的相对价值,需要连续对冲与 Greeks 管理。
