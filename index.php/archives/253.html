在使用 Git 进行版本控制时，了解项目中的文件更改是非常重要的。无论您是开发者、项目经理还是测试人员，获取文件更改列表可以帮助您快速了解代码的变动情况。本文将介绍如何使用 Git 导出项目中的文件更改列表。

1. 什么是文件更改列表？

文件更改列表指的是在某个提交（commit）或一系列提交之间所做的所有文件的修改记录。这些记录包括新增、修改和删除的文件。通过文件更改列表，您可以清晰地了解项目的演变过程。
