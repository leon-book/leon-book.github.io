使用 cURL 获取请求头和响应头

cURL 是一个强大的命令行工具，用于与服务器进行数据交换。在日常开发中，我们经常需要检查 HTTP 请求和响应的头信息。本文将介绍如何使用 cURL 获取请求头和响应头，以及一些常用的示例。

什么是 HTTP 头？

HTTP 头是请求和响应中附加的信息，包括元数据、内容类型、缓存控制等。通过查看这些头信息，我们可以更好地理解请求和响应的状态。
