xhprof 性能参数说明:

性能点 描述 :

  • Inclusive Time 包括子函数所有执行时间
  • Exclusive Time/Self Time 函数执行本身花费的时间，不包括子树执行时间
  • Wall Time 花去了的时间或挂钟时间
  • CPU Time 用户耗的时间 + 内核耗的时间
  • Inclusive CPU 包括子函数一起所占用的 CPU
  • Exclusive CPU 函数自身所占用的 CPU
