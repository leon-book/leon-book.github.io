发表于2023-04-17|更新于2023-04-17|数据库
|评论数:

代码如下：

转换为小写：
UPDATE 表名 SET 列名= lower( 列名 );

如果转换为大写：
UPDATE 表名 SET 列名= UCASE( 列名 );
