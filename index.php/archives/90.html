解决 Nginx 配置导致服务端获取客户端 IP 为 127.0.0.1 的问题

在使用 Nginx 进行配置时，有时会遇到服务端获取客户端 IP 一直为 127.0.0.1 的问题。这可能是由于配置不正确导致的。本篇博客将介绍一些解决该问题的方法。

解决方法

要解决这个问题，可以通过以下步骤来调整 Nginx 配置，确保正确获取客户端的 IP 地址。

1. 设置请求头

在 Nginx 配置文件中，使用 proxy_set_header 指令来设置请求头，以传递客户端的真实 IP 地址给后端服务。你可以设置 X-Real-IP 或 X-Forwarded-For 请求头。请尝试添加以下配置：

以上配置将客户端的真实 IP 地址作为请求头的一部分传递给后端服务。

2. 检查代理服务器设置

如果你的 Nginx 配置中使用了代理服务器（如反向代理），请确保代理服务器的配置正确。有时代理服务器会覆盖或修改客户端 IP 地址。确保代理服务器的配置中正确地传递客户端的 IP 地址给后端服务。

3. 检查防火墙或其他网络设备

防火墙或其他网络设备也可能干扰客户端 IP 地址的获取。检查网络设备的配置，确保其不会修改或隐藏客户端 IP 地址。

4. 检查后端服务配置

确保后端服务（在这里是 http://127.0.0.1:57203/）能够正确地处理客户端 IP 地址。后端服务可能需要额外的配置来获取真实的客户端 IP 地址。

5. 重启 Nginx

尝试上述解决方法后，重新启动 Nginx，并检查客户端 IP 地址是否正确传递给后端服务。

结论

通过设置正确的请求头和检查代理服务器、防火墙以及后端服务的配置，可以解决 Nginx 配置导致服务端获取客户端 IP 为 127.0.0.1 的问题。希望本篇博客对你有所帮助，在使用 Nginx 进行配置时能够正确获取客户端的 IP 地址！
