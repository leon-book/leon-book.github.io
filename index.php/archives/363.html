1. 使用 array_walk()

array_walk() 函数可以遍历数组并对每个元素应用一个回调函数。

2. 使用 array_map()

array_map() 函数对数组的每个元素应用回调函数，并返回一个新数组。

3. 使用生成器（Generators）

生成器可以在遍历大数组时节省内存。可以使用 yield 关键字创建生成器。

示例

4. 使用 array_reduce()

array_reduce() 函数可以将数组缩减为单一的值，通常用于累加或组合。

5. 使用 array_keys() 和 array_values()

通过 array_keys() 和 array_values() 函数，可以分别获取数组的键和值，然后进行遍历。

6. 使用 array_column()

当数组是多维数组时，可以使用 array_column() 提取出某个列，然后进行遍历。
